# @fundradar/shared

Shared TypeScript types used across the monorepo.

## Types

Defined in `src/types.ts`:

- `Fund` - Fund entity with profile data
- `Signal` - Observed change/event for a fund
- `Watchlist` - User watchlist
- `User` - User account

## Usage

```typescript
import { Fund, Signal } from '@fundradar/shared';
```

## Development

```bash
pnpm build    # Compile TypeScript
pnpm test     # Run tests
```
