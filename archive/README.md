# Archive

Historical and reference materials preserved for context but not actively used.

## Folders

### `/audits/`
Historical audit reports and investigation notes that are preserved for reference but are not part of the active workflow.

### `/branding/`
Unused or superseded brand/image assets that are kept for context but are not used by the app.

### `/reference/`
External guides and reference documents used during initial development:
- `claude-code-tips.md` - Best practices for Claude Code sessions
- `chat-gpt.md` - ChatGPT conversation excerpts for context

### `/scripts/`
Archived one-off scripts used for completed audits, cleanup passes, and migration work. Active operational scripts belong in `/scripts/` at the repo root.

### `/sprints/`
Completed sprint planning documents:
- `sprint-0-plan.md` through `sprint-4-plan.md`

These capture the original planning and decisions made. Current project status is tracked in `/docs/spec.md`.

### `/misc/`
Other archived files as needed.
